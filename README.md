# Forecast

Forecast is a softer kind of to-do list. Check in with the kind of day you’re having, choose a few things that fit inside it, and let the rest wait. It is designed to make planning feel more human for people who get overwhelmed by long task lists.

## What it does

- Choose an inner forecast: clear, cloudy, rainy, or windy. Each one offers a small prompt for planning at your own pace.
- Add tasks under Focus, Life, or Joy.
- Use gentle starter ideas when the blank page feels like too much.
- Mark tasks complete and see your progress shift with you.
- Keep tasks and your forecast saved in this browser on this device.

## Run it

Open `index.html` in a modern browser. No install or build step is needed.

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive layout and visual design
- `app.js` — check-in, task behavior, and browser storage

## Privacy

Tasks and the forecast choice are stored in this browser using `localStorage`; they are not sent to a server. Clearing this site’s browser data will remove them. The typefaces load from Google Fonts when you are online; system font fallbacks are included.
